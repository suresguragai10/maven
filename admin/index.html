How do I get a token? (one-time setup, ~1 minute)
  1. Go to GitHub → click your profile photo → Settings.
  2. Scroll to Developer settings (bottom of left sidebar).
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Under Repository access, choose "Only select repositories" and pick your site's repo.
  5. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as "No access".
  6. Set an expiration (e.g. 90 days) and click Generate token.
  7. Copy the token (starts with github_pat_) and paste it above. You won't be able to see it again on GitHub, so keep it somewhere safe — you'll need to paste it in again next time you open this page.
